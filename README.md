# CCP Campus Navigator — FINAL Handshake Prototype

This is the interactive version intended for portfolio / Handshake presentation.

## Working interactions
- Hamburger menu opens/closes the navigation drawer
- Light / dark mode toggle, with the preference stored locally
- Destination search / destination change
- Start location change
- Floor selector
- Accessible-route toggle
- Dynamic route overlay on the supplied campus floor plan
- Current-location button
- Clear Route
- Start / stop navigation state
- Elevator status information
- Report-an-issue prototype flow
- Responsive desktop/mobile layout

## How to run
Open `index.html` in a modern browser. No server or installation is required.

## Portfolio disclosure
